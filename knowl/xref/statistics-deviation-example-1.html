Example 19.8.4. Example 1.

The salaries for a random sample of 10 individuals are given below.
🔗
  • Part A: Calculate the deviation for each salary in the dataset.
    🔗
  • Part B: Use the Summary Statistics Calculator to find the average deviation for the dataset.
    🔗
🔗
Solution.
Part A
🔗
First, use the Summary Statistics Calculator to compute the average value of the data.
🔗
Now subtract 44.5 from each salary to compute each deviation.
🔗
Part B
🔗
To find the average deviation, create a second column in the tool with the computed deviations in the same order as the salary data.
🔗
Then close the spreadsheet and change the data column to the deviations column. The calculator recomputes the mean and shows \(\overline{x}=0\text{.}\)
🔗
So, the average value of the deviations of any dataset is always 0. This means average deviation from the mean is not, by itself, a useful measure of variability.
🔗
Note. Think back to balancing dot stacks around the mean: deficits below the mean are negative and excesses above the mean are positive, and these cancel when added.
🔗
Since positive and negative deviations cancel, their sum is always 0. Dividing by the number of data values still gives 0.
